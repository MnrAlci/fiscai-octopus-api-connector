# Export schema

Datasets written by `octopus_export_dataset` / `octopus-api-connector export` (CSV in UTF-8 with a header row, JSON with `schema` and `rijen`, xlsx, Parquet). The same columns are used in the dossier transfer. The column `administratie` holds the Octopus dossier id (shared name across FISCAi connectors). Amounts are EUR with sign `debet - credit` unless stated otherwise (verifieer actuele regel, see [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md)).

_Generated by `scripts/build_docs.py`._
