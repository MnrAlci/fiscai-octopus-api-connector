# Postman collection

> Intended for Belgian bookkeepers/accountants; based on Belgian accounting and VAT rules (MAR, Belgian VAT system). Use outside Belgium: verify the local rules yourself.
>
> Powered by FISCALCI Accounting & Tax (Askin Alci)

`postman/FISCAi-Octopus-API-Connector.postman_collection.json` is generated by `scripts/build_postman.py` from the official Octopus REST API specification (service.inaras.be). It contains **only the 50 read operations** in 21 folders, plus two set-up requests. Dutch: [POSTMAN.nl.md](POSTMAN.nl.md).

## Use
1. Import the collection and `postman/FISCAi-Octopus-API-Connector.postman_environment.json`.
2. Fill `softwareHouseUuid`, `user` and `password` in **your own** environment as *secret* values (never in the collection, never shared or synced to a team workspace).
3. Run **0. Aanmelden** (token, valid 10 minutes) and **1. Dossiertoken** (valid 10 minutes). Test scripts store the tokens in collection variables; repeat after 10 minutes.
4. Set `dossierId`, `bookyearId` and `modifiedTimeStamp` (format `2026-01-01 00:00:00.000`).

## Mind the daily limits
Every request counts towards the Octopus daily limits **and is not counted by the connector's quota file**. Some endpoints allow only 2 calls a day (accounts, VAT codes, relations without search...). Prefer the demo dossier for testing. Write operations are deliberately not included.

The CI checks that the collection is up to date and contains no secrets and no write methods.
